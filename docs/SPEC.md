# Spec — odin-webkit

## Packages

```
webkit/   package webkit: generated by runic from webkit/rune.yml
javascriptcore/   package javascriptcore: generated by runic from javascriptcore/rune.yml
```

Import through the `webkit` collection: `import "webkit:<package>"`.

## Surface

Every public declaration of the bound headers (WebKitGTK 6.0 and JavaScriptCore 2.52.6), named as runic names
them, plus the hand fixes in [PATCHED.md](PATCHED.md). Deprecated API is bound, because
`GLIB_DISABLE_DEPRECATION_WARNINGS` is set when generating.

## Version

The binding records the library version it was generated from. `make test` compares it
with the version macros of the installed headers.
