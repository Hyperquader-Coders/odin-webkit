# Patched bindings

The bindings are generated by runic (Amber's fork, branch `amber-patched`) from the C headers.
Two things change the generated output: rules that `make generate` applies every time, and
hand-written code. Regenerating applies the rules again and leaves hand-written files alone;
a typed pin in `<pkg>/patched.odin` makes a regeneration that drops a rule fail to compile.

To regenerate, run `make generate` and then `make ci`.

## Generation rules

`scripts/postprocess.sh <pkg>` applies these to `webkit/webkit.odin` and
`javascriptcore/javascriptcore.odin`, in this order. The structure is odin-glib's; the rules
are odin-gtk's, kept where they still apply to runic 0.8.

| rule | reason | pin |
|---|---|---|
| `^glib.char` becomes `cstring` | `gchar *` is a typedef'd char pointer, which runic leaves as a pointer to `char` | `patched_uri_request_get_uri`, `patched_value_to_string` |
| `TYPE_FOO :: \`(webkit_foo_get_type())\`` becomes `TYPE_FOO :: foo_get_type` (likewise `jsc_`) | the macro names the type function | `patched_type_web_view`, `patched_type_value` |
| `NETWORK_ERROR` and the other `*_ERROR` macros become the `*_error_quark` procedures | as above | `patched_network_error` |
| `MAJOR_VERSION`, `MINOR_VERSION`, `MICRO_VERSION` lose their backticks and parentheses | the version test reads them as numbers | `patched_major_version` |
| `Foo :: _WebKitFoo` is deleted and `_WebKitFoo` becomes `Foo` (likewise `_JSC`) | one name per struct | none |
| the GFlags enums listed in `postprocess.sh` (`webkit_flags`, `jsc_flags`) become `FooBit :: enum u32` of bit indices plus `Foo :: bit_set[FooBit; u32]`; zero members and composite masks become constants of `Foo` | `{.CASE_INSENSITIVE, .WRAP_AROUND}` instead of integer ORs; the size and bits are those of C; see DECISIONS §7 | `test_flag_bits_match_the_header` |
| `gobj.Value` becomes `jsc.Value`, and the `jsc` import is added if runic left it out | `GValue` and `JSCValue` both trim to `Value`, and runic picks one per run for the three `JSCValue` procedures | none: the generated file is compared across two `make generate` runs |
| Every procedure parameter is `^T` (`^^T` for `T **`) unless `arrays:` lists it (`detect.parameters: declared` in `webkit/rune.yml` and `javascriptcore/rune.yml`; no postprocess rule) | runic writes `[^]T` for any pointer parameter whose name ends in "s"; the headers pass one `T *` for `settings`, `proxy_settings`, `policies`, `cookies`, `headers`, `errors` and the rest, and one `T **` for `underlines`, `field_names` and `field_values`. `files`, `languages`, `ignore_hosts` (string vectors), `parameters` (`JSCValue **` with a count) and `parameter_types` (`GType *` with a count) are arrays, listed under `arrays:` | `patched_settings_apply_from_key_file`, `patched_memory_pressure_settings_copy`, `patched_window_properties_get_fullscreen`, `patched_class_add_constructor_variadic` and one pin for each other parameter |
| `exception_new_vprintf` and `exception_new_with_name_vprintf` are skipped by the fork (a comment marks each place in `javascriptcore.odin`) | they take a `va_list`; the unpatched runic drops it and marks the procedure `#c_vararg ..any`, so a call is wrong. The `...` procedures (`exception_new_printf`, `value_function_call`, ...) are correct | `scripts/check-generated.sh` |
| `[^]^T` parameters are checked, not rewritten | as above. `parameters` of `value_object_invoke_methodv`, `value_function_callv` and `value_constructor_callv` is `JSCValue **` with `n_parameters`: an array, stays | `scripts/check-generated.sh` fails on any other `[^]^T` |

`rune.yml` ignores the `_*`, `*AVAILABLE*`, `WEBKIT_API`, `WEBKIT_DEPRECATED*`, `JSC_API`
and `JSC_DEPRECATED*` macros, and `webkit` also ignores every `GDK_*`, `GSK_*` and `GTK_*`
macro, which belong to `gtk4`.

Hand-written code: none.
